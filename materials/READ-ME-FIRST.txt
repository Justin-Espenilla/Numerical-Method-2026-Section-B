NUMERICAL METHODS LABORATORY

Every .html file in this folder is self-contained. Double-click any of
them to open it in a browser. No internet connection is required and
nothing needs to be installed to READ them.

  lab-assignment-NN.html   the assignment for laboratory NN
  grading.html             grading system, rubrics and the AI policy
  setup.html               how to install Python before Laboratory 1
  labNN_demo.py            the program shown in that lecture
  labNN_starter.py         the skeleton to start your assignment from

To RUN the .py files you need Python 3 with NumPy and Matplotlib.
See setup.html.
