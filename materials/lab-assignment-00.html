The one step everyone gets wrong

On the very first screen of the Python installer there is a tick box reading "Add python.exe to PATH". Tick it before pressing Install. If you miss it, the python command will not be recognised in the terminal and you will have to uninstall and start again. This single box is the cause of most first-week problems.

A.1 Confirm Python is installed

Open a terminal — in VS Code, Terminal → New Terminal — and type:

python --version

You should see something like Python 3.12.6. Any version 3.11 or later is fine. If you instead see "python is not recognised", the PATH box was missed: uninstall Python and repeat Video 1.

A.2 Confirm VS Code can run a file

Create a file called hello.py, type the line below, save it, and press the ▶ Run button.

print("Python is working")

If VS Code asks you to select an interpreter, choose the Python 3 you just installed. If the message appears in the terminal, Part A is complete.

D.2 Verify them

Create a file named lab00_check_<surname>.py, type in the program below exactly, fill in your name and student number at the top, and run it. Type it rather than copying it: it is the first Python you will write for this course, and the habits start here.

"""
Lab Assignment 0 - platform verification
Name           : <your name>
Student number : <your student number>
"""
import os
import sys

import numpy as np
import scipy
from scipy import integrate
import matplotlib
import matplotlib.pyplot as plt

# ---- 1. report the versions --------------------------------------------
print("Python     :", sys.version.split()[0])
print("NumPy      :", np.__version__)
print("SciPy      :", scipy.__version__)
print("Matplotlib :", matplotlib.__version__)

# ---- 2. a NumPy calculation --------------------------------------------
# 200 points from 0 to 2*pi, then the sine of every one of them at once.
x = np.linspace(0, 2*np.pi, 200)
y = np.sin(x)
print("\nmean of sin(x) over one period :", round(float(y.mean()), 12))

# ---- 3. a SciPy cross-check --------------------------------------------
# The integral of sin(x) from 0 to pi is exactly 2.
area, _ = integrate.quad(np.sin, 0, np.pi)
print("integral of sin(x) from 0 to pi :", round(area, 12), "(exact value 2)")

# ---- 4. a Matplotlib figure --------------------------------------------
os.makedirs("figures", exist_ok=True)
plt.rcParams.update({"figure.dpi": 150})

fig, ax = plt.subplots(figsize=(5.2, 3.2))
ax.plot(x, y, color="#0b5fa5", lw=1.6, label="sin(x)")
ax.plot(x, np.cos(x), color="#8a5b00", lw=1.2, ls="--", label="cos(x)")
ax.set_xlabel("x (radians)")
ax.set_ylabel("value")
ax.set_title("Lab Assignment 0 - platform check")
ax.grid(True, alpha=0.3)
ax.legend()
fig.tight_layout()
fig.savefig("figures/lab00_check.png")

print("\nfigure written to figures/lab00_check.png")
print("PLATFORM READY.")

Run the program from the terminal so that the output is saved to a file. On Windows PowerShell:

On macOS or Linux:

python lab00_check_<surname>.py > lab00_output_<surname>.txt

The last line of that file must read PLATFORM READY. If it does not, the assignment is not complete.

If you see ModuleNotFoundError

ModuleNotFoundError: No module named 'numpy' means Python is running from a different installation than the one pip installed into. The fix is almost always to use python -m pip install ... — with the python -m prefix — rather than pip install ... on its own, and to check that VS Code has selected the same interpreter (bottom-right corner of the window).
