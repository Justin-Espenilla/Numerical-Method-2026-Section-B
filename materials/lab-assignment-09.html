Lab Assignment 9 · 100 points

Normal Depth and the Order of a Method

Derive the finite-difference formulas from Taylor's expansion, measure the remainder against its theoretical bound, then use Newton–Raphson to solve a channel design problem and demonstrate the three ways it fails.

Part A — Derivation and the remainder 25 pts

  1. A.1 Derive, by hand and shown in the report, the forward, backward and centred first derivative formulas and the centred second derivative formula, stating the leading error term of each. Marks are for the derivation, not the result.
  2. A.2 Derive the three-point forward formula (−3f0 + 4f1 − f2)/2h and prove it is O(h2). This is the endpoint formula used since Lab 1.
  3. A.3 For f(x) = ex/2sin x expanded about x = 1.0, tabulate the approximation to f(1.3) using 1, 2, 3, 4 and 5 terms, with the true error of each.
  4. A.4 For each row of A.3, compute the theoretical remainder bound |f(n+1)|maxhn+1/(n+1)! over the interval, and confirm the actual error never exceeds it. Present bound and actual side by side.
  5. A.5 Repeat A.3 with h = 0.6 instead of 0.3 and confirm that each term's error grows by the factor its order predicts.

Part B — Normal depth by Newton–Raphson 30 pts

Design a trapezoidal drainage channel: base width b = 3.0 m, side slopes z = 2, Manning's n = 0.025, bed slope S = 0.001, design discharge Q = 15 m³/s.

  1. B.1 Implement newton(f, fprime, x0, es, max_iter) returning (root, iterations, ea, history), with a guard against a vanishing derivative and an iteration cap.
  2. B.2 Solve for the normal depth from y0 = 1.0 m. Reproduce the iteration table of the lecture: yi, f(yi), f′(yi), yi+1 and εa. Report the depth, area, hydraulic radius and mean velocity.
  3. B.3 Demonstrate quadratic convergence. Tabulate log10|εt| at each iteration and show that it approximately doubles. State the observed order by fitting log|ei+1| against log|ei|; the slope should be near 2.
  4. B.4 Solve the same problem by bisection on the bracket [0.1, 10] m to the same tolerance. Report the iteration count for both methods and the ratio. State the trade-off in one sentence.
  5. B.5 Derive f′(y) analytically by hand and implement it. Compare iterations, runtime and final depth against the numerical-derivative version.
  6. B.6 Produce a design chart: normal depth against discharge for Q from 1 to 50 m³/s. Mark the design point. State the depth at which the channel would overtop a 2.5 m deep section and the discharge that causes it.

Part C — Making it fail 25 pts

  1. C.1 Start Newton from y0 = 0.01 m and record what happens. Report the iterates and explain the behaviour in terms of the derivative near y = 0.
  2. C.2 Find a starting value from which the method converges to a physically meaningless root, and report both the starting value and the root. State how an engineer would detect this in practice.
  3. C.3 Apply Newton to g(x) = x3 − 2x + 2 from x0 = 0. Report the first ten iterates and identify the cycle. Explain why a Taylor argument does not forbid this.
  4. C.4 Implement a safeguarded solver: attempt a Newton step; if it leaves the bracket or fails to reduce |f|, take a bisection step instead. Demonstrate that it solves all three cases above. Report iteration counts against plain Newton where both succeed.
The point of Part C

Fast methods that occasionally fail and safe methods that are always slow are both unacceptable in production code. Every professional root-finder is a hybrid. Building one is the most transferable thing in this assignment.

Part D — AI Prompt Log 20 pts

Required prompt experiment — the unguarded solver

Send this prompt, word for word:

write newton raphson method in python to find normal depth in an open channel

Then, in the log:

  1. Does the returned code guard against a zero derivative? Does it cap the iterations? Quote the lines, or state that they are absent.
  2. Run it from y0 = 0.01 and record the outcome exactly — including any exception traceback.
  3. Check its hydraulics, not just its arithmetic: is the wetted perimeter b + 2y√(1+z2)? Is R = A/P? Is the exponent 2/3 and not 3/2? Report every discrepancy with the corrected line.
  4. Write an improved prompt specifying the channel geometry, the guards, the stopping criterion and the returned history. Compare the two answers.
  5. Name one defect that remains in the improved answer.

Note for this assignment in particular: an AI error in the hydraulics is far more dangerous than an error in the numerics, because the code still runs and still converges — to the wrong depth. Say in two sentences how you would catch such an error on a real project.
