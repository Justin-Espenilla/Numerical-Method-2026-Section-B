Lab Lecture 6 · Lecture topic: Matrices

The Matrix as a Machine

A truss with ten members produces ten equations that must be satisfied at the same instant. No member can be solved first. This lab covers the standard method for solving such systems — Gauss elimination with partial pivoting — and the reason a structural analysis can fail on a matrix that looks perfectly ordinary.

1. Where the equations come from

Case file — pin-jointed roof truss, method of joints

A designer analysing a small roof truss writes the equilibrium equations joint by joint. At each pin, ΣFx = 0 and ΣFy = 0. Six joints give twelve equations; the truss has nine members and three reaction components, so there are twelve unknowns.

Solving them by hand means choosing a joint with only two unknowns, solving it, substituting forward, and hoping the arithmetic holds. It works for a textbook truss. It does not work for the 400-member frame the designer will meet in practice, and it does not work at all when no joint has fewer than three unknowns.

Written in full, a system of n simultaneous linear equations is

a11x1 + a12x2 + … + a1nxn = b1
a21x1 + a22x2 + … + a2nxn = b2
…
an1x1 + … + annxn = bn

Collect the coefficients into a matrix and the equations become [A]{x} = {b}. The matrix is not a decorative arrangement of numbers. It is the structure itself: row i is one equilibrium condition, column j is the influence of member j on every equation it appears in.

2. Matrix–vector multiplication is the model, evaluated

Before solving anything, be clear about what a matrix–vector product does. {b} = [A]{x} takes a set of member forces and reports the resulting net force at every joint. It runs the model forwards.

import numpy as np

def matvec(A, x):
    """b = A x, written out. Row i of A dotted with x gives equation i."""
    n, m = A.shape
    b = np.zeros(n)
    for i in range(n):
        for j in range(m):
            b[i] += A[i, j] * x[j]
    return b

Solving [A]{x} = {b} runs the model backwards: the loads are known and the forces that produce them are not. Running a model backwards is almost always the harder direction, and that asymmetry is the reason this lab exists.

Never invert the matrix

The formula {x} = [A]−1{b} is correct mathematics and poor computing. Forming the inverse costs about three times as much arithmetic as solving directly, and it is less accurate, because every entry of the inverse carries its own accumulated round-off. In forty years of practice the number of civil engineering calculations that genuinely require an explicit inverse is close to zero. Use elimination.

3. Gauss elimination

The method has two phases and one idea. The idea: adding a multiple of one equation to another does not change the solution, so we may do it freely until the system becomes trivial to read off.

3.1 Forward elimination

Use the first equation to remove x1 from all the others; use the new second equation to remove x2 from those below it; continue. The result is an upper triangular matrix — the last equation contains a single unknown.

3.2 Back substitution

Solve the last equation, substitute upwards, and work back to the first.

def gauss_naive(A, b):
    """Solve Ax = b by Gauss elimination without pivoting. Instructional only."""
    A = np.array(A, float)          # copy: never modify the caller's data
    b = np.array(b, float)
    n = len(b)

    # forward elimination
    for k in range(n - 1):
        for i in range(k + 1, n):
            factor = A[i, k] / A[k, k]              # <-- the weak point
            A[i, k:] -= factor * A[k, k:]
            b[i]     -= factor * b[k]

    # back substitution
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - A[i, i+1:] @ x[i+1:]) / A[i, i]
    return x

The cost is roughly n3/3 multiplications. Doubling the size of the structure multiplies the work by eight. A 400-member frame is 4003/3 ≈ 21 million operations, which a laptop completes in well under a second; a 40,000-member model is 21 × 1012, which it does not. That gap is what Lab 7 addresses.

4. Why the naive version fails

The marked line divides by A[k, k], the pivot. Two things go wrong with it.

4.1 A zero pivot

[A] = 0  2  1
1  3  2
2  1  4

Nothing is wrong with this system; it has a perfectly good unique solution. But the first pivot is zero, the code divides by zero, and the answer comes back as nan. In a truss this happens whenever the first joint has no member acting along the first coordinate direction — that is, routinely.

4.2 A small pivot, which is worse

A zero pivot announces itself. A small one does not. Consider

0.0003x1 + 3.0000x2 = 2.0001     1.0000x1 + 1.0000x2 = 1.0000

The exact solution is x1 = 1⁄3, x2 = 2⁄3. Eliminate using the first row as the pivot and the multiplier is 1/0.0003 = 3333. That multiplier magnifies the round-off already present in the first row by a factor of three thousand before subtracting it from the second. Carried at five significant figures, the computed answer for x1 comes out as −3.33 — wrong in sign, wrong in magnitude, and produced without any warning.

Partial pivoting

Before eliminating in column k, find the row at or below k with the largest absolute value in that column, and swap it into the pivot position. Every multiplier is then at most 1 in magnitude, so no error is amplified. The cost is a search and a row swap — a few per cent of the total runtime. There is no situation in which you should omit it.

def gauss_pivot(A, b, tol=1e-12):
    """Solve Ax = b by Gauss elimination with partial pivoting.

    Returns x. Raises ValueError if the matrix is numerically singular.
    """
    A = np.array(A, float)
    b = np.array(b, float)
    n = len(b)

    for k in range(n - 1):
        p = k + int(np.argmax(np.abs(A[k:, k])))     # largest pivot available
        if abs(A[p, k]) < tol:
            raise ValueError(f"Matrix is singular at column {k}.")
        if p != k:
            A[[k, p]] = A[[p, k]]                    # swap rows
            b[[k, p]] = b[[p, k]]

        for i in range(k + 1, n):
            factor = A[i, k] / A[k, k]               # now |factor| <= 1
            A[i, k:] -= factor * A[k, k:]
            b[i]     -= factor * b[k]

    if abs(A[-1, -1]) < tol:
        raise ValueError("Matrix is singular at the last pivot.")

    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - A[i, i+1:] @ x[i+1:]) / A[i, i]
    return x

5. Checking the answer

A linear solver returns numbers whatever you give it. Two checks separate a result from a guess.

5.1 The residual

r = b - A @ x
print(f"max |residual| = {np.max(np.abs(r)):.3e}")

The residual should be at the level of round-off relative to the size of {b} — around 10−12 for entries of order 1. A large residual means the solve failed. A small residual, however, does not by itself prove the answer is accurate; that is the subject of Lab 7.

5.2 Equilibrium, in the language of the problem

For a truss, substitute the member forces back into the joint equations and confirm that ΣFx and ΣFy vanish at every pin, and that the reactions sum to the applied load. This catches errors the residual cannot: a sign convention reversed when the matrix was assembled produces a system that is solved perfectly and describes the wrong structure.

Where the real errors are

In practice almost no marks are lost inside the elimination routine, which is short and testable. They are lost in assembling [A]: a member angle measured from the wrong axis, a compression taken as positive in one joint and negative in another, a support condition omitted. Build the matrix for a three-member truss you can check by hand before trusting it with nine.

6.2 Step 1 — choose the pivot

Column 1 holds 0.8660, 0.5000 and 0.0000. The largest magnitude is already in row 1, so no swap is needed. Had the equations been written in a different order — and a student assembling by joints will produce a different order — the swap would have been essential.

6.3 Step 2 — eliminate column 1

Multiplier for row 2: 0.5000 / 0.8660 = 0.57737. Row 3 already has a zero, so it is untouched.

R2 ← R2 − 0.57737 R1:    [0, 1.0000, 1.11536 | −10.0000]

6.4 Step 3 — eliminate column 2

Pivot 1.0000 in row 2; multiplier for row 3 is 1.0000/1.0000 = 1.

R3 ← R3 − 1.0 R2:    [0, 0, −1.11536 | 6.0000]

6.5 Step 4 — back substitution

F3 = 6.0000 / (−1.11536) = −5.3794 kN
F2 = −10.0000 − 1.11536(−5.3794) = −4.0000 kN
F1 = [0 + 0.7071(−5.3794)] / 0.8660 = −4.3924 kN

7. Where it breaks

Singular matrix

A mechanism rather than a structure: too few members, or members arranged so that the truss can move without straining. Elimination reaches a zero pivot it cannot swap away. The correct response is to fix the structure, not the code.

Nearly singular

Two members almost parallel. The system solves, the residual is small, and the answer is still unreliable. Lab 7 introduces the condition number, which measures exactly this.

Mixed units

Forces in newtons and displacements in metres produce coefficients spanning 109. Elimination survives it, but accuracy suffers. Scale the equations so the coefficients are of comparable size.

Cost

n3/3 operations, and memory for n2 entries. A 10,000-node seepage mesh would need 800 MB for a dense matrix that is 99.9 % zeros. Sparse and iterative methods exist for exactly this reason.
