Taylor Series: The Source of Every Method in This Course

The finite-difference formulas of Lab 1, the error orders quoted in Labs 4 and 5, the uncertainty propagation of Lab 2 and the root-finding method used for every normal-depth calculation in hydraulics all come from one expansion. This lab derives them, and shows what the remainder term is for.

1. What the expansion says

f(x+h) = f(x) + f′(x)h + f″(x)2!h2 + f′′′(x)3!h3 + … + Rn

Read as engineering rather than as algebra: standing at x, where the value, slope and curvature are known, the expansion predicts the value a distance h away. Keeping one term assumes the function is flat; two terms assume it is straight; three assume it is a parabola. The remainder

Rn = f(n+1)(ξ)(n+1)! hn+1   =   O(hn+1)

states the price of stopping. It is why every method in this course carries an order, and why halving a step size divides an O(h2) error by four and an O(h4) error by sixteen.

2. Deriving the finite differences you have been using

Lab 1 presented three difference formulas without proof. Here they are, derived.

2.1 Forward difference

Truncate after the first-derivative term:

f(x+h) = f(x) + f′(x)h + f″2h2 + …  ⇒  f′(x) = f(x+h) − f(x)h − f″2h − …

The discarded terms begin with a multiple of h: the formula is O(h), first order. The leading error is −f″h/2, so on a strongly curved function the forward difference is not merely inaccurate but biased in a predictable direction.

2.2 Centred difference

Write both expansions and subtract:

f(x+h) = f + f′h + f″h2/2 + f′′′h3/6 + …
f(x−h) = f − f′h + f″h2/2 − f′′′h3/6 + …
⇒  f′(x) = f(x+h) − f(x−h)2h − f′′′6h2 − …
Why centred is second order

The f″h2/2 terms are identical in both expansions, so subtraction removes them exactly. The first surviving error term involves h2. This is the entire reason the centred formula is more accurate at no extra cost, and it explains the observation in Lab 1 that a cubic gives a centred error ratio of exactly 4.00: for a cubic, f′′′ is constant and no higher terms exist.

2.3 Second derivative

Add the two expansions instead of subtracting. The odd-order terms cancel:

f″(x) = f(x+h) − 2f(x) + f(x−h)h2 − f(4)12h2 − …

This is the stencil behind the seepage grid of Lab 7 and the beam equation of Lab 10. Every finite-element and finite-difference model a civil engineer runs is built from expansions of this kind.

3. Newton–Raphson: a two-term Taylor series, solved

Case file — trapezoidal channel, normal depth

A drainage channel is to carry 15 m³/s. Base width 3.0 m, side slopes 2 horizontal to 1 vertical, Manning's n = 0.025, bed slope 0.001. What depth will the flow settle at?

Manning's equation gives the discharge for a given depth. The engineer needs the reverse, and the depth appears inside the area, inside the perimeter, and inside a two-thirds power. There is no rearrangement.

f(y) = 1n A(y) R(y)2/3√S − Q = 0,    A = (b+zy)y,   P = b + 2y√(1+z2),   R = A/P

Expand f about the current guess and keep two terms:

0 = f(yi) + f′(yi)(yi+1 − yi)  ⇒  yi+1 = yi − f(yi)f′(yi)

Newton–Raphson is nothing more than the tangent-line prediction of Taylor's expansion, solved for the point where the tangent crosses zero. The neglected term is the h2 curvature term, and because the error is squared at each step the number of correct digits roughly doubles per iteration.

4. Worked example: normal depth, iteration by iteration

import numpy as np

b, z, n, S, Q = 3.0, 2.0, 0.025, 0.001, 15.0

def f(y):
    A = (b + z*y) * y
    P = b + 2*y*np.sqrt(1 + z*z)
    R = A / P
    return (1/n) * A * R**(2/3) * np.sqrt(S) - Q

def fprime(y, h=1e-6):
    """Numerical derivative - Lab 1's centred difference, reused."""
    return (f(y + h) - f(y - h)) / (2*h)

def newton(y0, es=1e-6, max_iter=50):
    y = y0
    for i in range(max_iter):
        fy, fpy = f(y), fprime(y)
        if abs(fpy) < 1e-14:
            raise RuntimeError("Derivative vanished; Newton cannot proceed.")
        y_new = y - fy / fpy
        ea = abs((y_new - y) / y_new) * 100
        y = y_new
        if ea < es:
            return y, i + 1, ea
    return y, max_iter, ea

Follow the εa column: 52 %, 17 %, 1.8 %, 0.020 %, 0.0000024 %, 10−14 %. Once the iteration is near the root the number of correct digits doubles each step — 2, then 4, then 8, then 14. That is quadratic convergence, and it is what the discarded h2 term in the Taylor expansion buys you.

Compare with a bracketing method on the same problem: bisection gains about one bit — 0.3 of a decimal digit — per iteration, and would need roughly 45 iterations to match what Newton achieves in five. The price is that bisection cannot fail and Newton can.

5. Taylor also gives the error propagation of Lab 2

Expand a function of several uncertain inputs about their nominal values and keep the first-order terms:

Δf ≈ ∑j ∂f∂xj Δxj

That is exactly the worst-case propagation formula used on the beam in Lab 2, and the reason it fails for large uncertainties is now visible: the neglected term is quadratic in Δx. When the Monte Carlo mean came out above the nominal deflection, that displacement was the neglected second-order term, made visible.

6. Where it breaks

Zero or near-zero derivative

The tangent is flat and the next iterate is thrown far away. In channel hydraulics this happens near critical depth. Guard the division and fall back to bisection.

A poor starting guess

Newton converges to a root, not necessarily the physical one. A negative depth is mathematically valid and hydraulically meaningless. Always bracket the physical range first.

Oscillation

Some functions send the iterate cycling between two values indefinitely. Cap the iterations and report non-convergence rather than returning the last value silently.

Functions that are not smooth

Taylor's theorem requires derivatives to exist. A tabulated rating curve with a kink has no second derivative at the kink, and every order estimate in this course is void there.
