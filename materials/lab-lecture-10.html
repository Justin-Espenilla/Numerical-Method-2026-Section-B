Capstone: One Beam, Every Method

A single structural problem that requires integration to find the load effects, differentiation to recover rotations, a matrix to solve the governing equation, a Taylor argument to justify the mesh, and a sensitivity study to size the section. This is what the previous nine laboratories were for.

1. The problem

Case file — footbridge deck, serviceability check

A simply supported deck spans 6.0 m and carries a uniformly distributed load of 20 kN/m. The section is not constant: it is haunched, so the flexural rigidity EI varies along the span. The designer needs the maximum deflection, the rotation at the supports, and an answer to the question of how deep the section must be to satisfy span/360.

No closed-form solution exists once EI varies. The problem must be discretised.

The governing equation is the Euler–Bernoulli relation between curvature and moment:

d2ydx2 = M(x)E I(x)     y(0) = y(L) = 0

3. Discretising the governing equation

Divide the span into n intervals of width h = L/n. Replace the second derivative by the centred difference derived in Lab 9:

yi−1 − 2yi + yi+1h2 = MiEIi   ⇒   yi−1 − 2yi + yi+1 = h2 MiEIi

Writing this at every interior node produces n−1 equations in n−1 unknown deflections. The matrix is tridiagonal: each node is coupled only to its immediate neighbours, which is the same locality that made the seepage grid of Lab 7 diagonally dominant.

import numpy as np

def beam_deflection(L, n, M_func, EI_func):
    """Deflection of a simply supported beam by finite differences.

    Returns (x, y) with y = 0 imposed at both supports.
    """
    h = L / n
    x = np.linspace(0, L, n + 1)

    A = np.zeros((n - 1, n - 1))
    b = np.zeros(n - 1)
    for i in range(n - 1):
        A[i, i] = -2.0
        if i > 0:
            A[i, i-1] = 1.0
        if i < n - 2:
            A[i, i+1] = 1.0
        b[i] = h*h * M_func(x[i+1]) / EI_func(x[i+1])

    y = np.zeros(n + 1)
    y[1:n] = np.linalg.solve(A, b)      # replace with your Lab 6 solver
    return x, y
Note the boundary conditions

The supports are not equations in the system; they are known values that never enter it. The first interior node's equation would have contained y0, but y0 = 0, so the term vanishes. This is why the matrix has n−1 rows and not n+1. Getting this bookkeeping wrong is the single most common failure in the assignment; a system that is one row too large will still solve and will still return plausible numbers.

What this table proves

The error ratio is 4.000 at every refinement, which is the signature of an O(h2) method — exactly what the Taylor derivation in Lab 9 predicted for the centred second difference. Three conclusions follow:

  1. The implementation is correct. A ratio of 2.000 would indicate a first-order error somewhere, almost always in the boundary treatment.
  2. The mesh can be justified in writing: n = 32 gives 0.08 % error, which is far inside the tolerance of any real load estimate.
  3. Richardson extrapolation applies. Combining n = 32 and n = 64 as (4y64 − y32)/3 gives 1.687500 mm — the exact answer to six figures, from two coarse solutions.

Differentiating the computed deflection with the Lab 1 routine gives the rotation. At n = 64 the maximum rotation is 0.000900 rad, against the theoretical wL3/24EI = 0.000900 rad. The support rotation matters because it governs bearing selection and the movement joint at the abutment.

5. The design question

With a verified analysis, the design question becomes tractable. For a rectangular section of width b and depth d, I = bd3/12, so the deflection scales as d−3. From Lab 2, the dimensionless sensitivity of deflection to depth is exactly −3: a 1 % deeper section reduces deflection by 3 %.

The serviceability limit is span/360 = 16.67 mm. Finding the depth that just satisfies it is a one-dimensional root-finding problem — Newton–Raphson from Lab 9, or a simple bisection on depth. Finding the depth that satisfies it at least cost is a one-dimensional optimisation — Lab 3.

The discretisation must be settled first

Optimising on a mesh that has not been shown to converge produces a section sized against numerical error. Establish the convergence table, choose the mesh, fix it, and only then run the design search. Reporting an optimum without the convergence evidence is the most serious error available in this assignment.

6. Where it breaks

Boundary bookkeeping

An extra row, or a known deflection left in the unknown vector. The system still solves. Check against the constant-EI exact answer before anything else.

Abrupt changes in EI

A step change in section violates the smoothness Taylor's theorem assumes. The order drops from 2 to 1 near the step and the ratio test will show it. Refine locally or place a node exactly at the step.

Mesh too fine

The matrix condition number grows as h−2. Beyond a few thousand nodes, round-off begins to undo what refinement gains — the V-curve of Lab 1, at the level of a whole structural model.

Wrong moment diagram

If M(x) is wrong, everything downstream is wrong and every numerical check still passes. Verify the moment diagram against statics by hand at three sections.

8. What the course was for

  • A derivative is a rate, a sensitivity, and a search direction, and it amplifies noise.
  • An integral is an accumulation, and it suppresses noise.
  • A matrix is a model of a system that must be satisfied all at once.
  • A series must be stopped on evidence, not habit.
  • Taylor's expansion supplies the formulas and the error terms for all of it.
  • And every result is worth exactly as much as the verification attached to it.
