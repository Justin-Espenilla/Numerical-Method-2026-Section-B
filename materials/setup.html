Before Laboratory 1

Environment Setup

Every laboratory in this course runs on Python 3 with NumPy and Matplotlib, and nothing else. No other package is required at any point, and none may be used for the methods themselves.

1. Option A — install locally (recommended)

  1. Install Python 3.11 or later from python.org. On Windows, tick "Add python.exe to PATH" during installation. Omitting this is the cause of most first-week problems.
  2. Install Visual Studio Code, then its Python extension.
  3. Open a terminal and install the two libraries: 
    python -m pip install --upgrade pip
python -m pip install numpy matplotlib
  4. Verify: 
    python -c "import numpy, matplotlib; print(numpy.__version__, matplotlib.__version__)"

2. Option B — run in a browser

Google Colab requires no installation and has NumPy and Matplotlib pre-installed. It is acceptable for every assignment. Two cautions: download your notebook as a .py file before submitting, because a notebook is not an acceptable deliverable; and confirm the code runs top to bottom after a fresh restart, since a notebook that depends on cells run out of order will not run for the marker.

3. The one convention that matters

Every submitted program must run from top to bottom on a clean machine and produce every number and figure in the report. Test this before submitting: restart the interpreter, run the file once, and check that the console output and the figures folder are complete.

# The standard header for every assignment in this course
import numpy as np
import matplotlib.pyplot as plt

SEED = 42          # the last two digits of your student number
rng = np.random.default_rng(SEED)

# save figures rather than only displaying them
import os
os.makedirs("figures", exist_ok=True)
plt.rcParams.update({"figure.dpi": 150})
# ... plot ...
plt.savefig("figures/fig_01_convergence.png", bbox_inches="tight")

4. Capturing the console output

Every submission includes a text file of the program's console output. Produce it by redirecting:

python lab01_<surname>.py > lab01_output_<surname>.txt

On Windows PowerShell, use python lab01_surname.py | Out-File -Encoding utf8 lab01_output_surname.txt.

5. What may not be used

FunctionStatusReason
np.gradientCross-check onlyLabs 1 and 10 assess your own difference formulas.
np.trapz, scipy.integrateCross-check onlyLabs 4 and 5 assess your own quadrature.
np.linalg.solve, scipy.linalgCross-check onlyLabs 6, 7 and 10 assess your own elimination.
scipy.optimize, curve_fitCross-check onlyLabs 3 and 9 assess your own iteration.
np.linalg.cond, np.finfoPermittedDiagnostics, not methods.
NumPy array arithmetic, slicing, @Permitted throughoutThese are the arithmetic, not the method.

"Cross-check only" means you may call it to confirm your own result, and you must label it as a check in both the code and the report. Presenting a library result as your own implementation is treated as a misrepresentation, not a shortcut.
