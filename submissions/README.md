# Submissions — Section B

One folder per student, named `surname-firstname` in lower case with hyphens.

```
submissions/
    delacruz-juan/
        README.md          name and student number
        lab00/
        lab01/
        lab02/
        ...
    santos-maria/
        ...
```

See `../SUBMISSION-GUIDE.md` for the step-by-step procedure.

`_EXAMPLE-surname-firstname/` shows the expected shape of a completed
laboratory folder. Do not put work in it.
